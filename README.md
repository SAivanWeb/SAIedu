# SAIedu

Локальная библиотека курсов на Vue 3, TypeScript и Naive UI. Курсы импортируются
из JSON и доступны без аккаунта. Библиотеку сохраняет локальный сервер приложения.

## Запуск

Подойдёт Node.js 22.12+ или 24 LTS. При первом запуске нужен доступ к npm.

```sh
npm ci
npm run dev -- --open
```

Друзьям можно передать копию проекта. На macOS для запуска подойдёт
`SAIedu.command`, на Windows — `SAIedu.cmd`. Скрипты устанавливают
зависимости при первом запуске и открывают браузер. На macOS при потере
исполняемого бита выполни `chmod +x SAIedu.command` в папке проекта.
Для остановки нажми кнопку питания рядом с переключателем темы и подтверди
действие. Можно также нажать Ctrl+C в окне запуска.

Адрес приложения — http://localhost:4173. Готовую сборку из `dist/` можно
запустить командой `npm run preview` из папки проекта. Оба способа запуска
используют одну библиотеку.

## Курсы и прогресс

1. Скачай шаблон в приложении или возьми [course-prompt.txt](public/course-prompt.txt).
2. Заполни тему, цели и материалы и передай шаблон нейросети. Сохрани результат
   в файле `.json`.
3. Нажми «Загрузить курс». Можно выбрать сразу несколько JSON-файлов.
4. В уроках вводи ответы в блоках практики и отмечай уроки пройденными.
   Ответы и прогресс сохраняются автоматически.

Курсы, прогресс и ответы хранятся в `data/library.json` рядом с папкой
`dist/`. Файл создаётся при первом сохранении и сохраняется при пересборке.
Другой браузер загружает ту же библиотеку при открытии или обновлении страницы.
Для переноса на другой компьютер скопируй папку `data/` вместе с проектом.

Для переноса данных из предыдущей версии открой SAIedu по прежнему адресу
в каждом браузере, где учился. При первом открытии приложение перенесёт
старые курсы и прогресс на диск. Для совпадающих идентификаторов курса
списки пройденных уроков объединяются, а при совпадении ответа или результата
теста сохраняется значение, уже записанное на диске.

В первой версии блоки практики сохраняют текстовые ответы, в том числе
фрагменты кода. Выполнять задания можно в программе, для которой они составлены.

## Установка и обновление через Git

Установи Git и Node.js, затем один раз клонируй проект:

```sh
git clone https://github.com/SAivanWeb/SAIedu.git
cd SAIedu
```

Запускай через `SAIedu.command` на macOS или `SAIedu.cmd` на Windows.
Из терминала можно запустить `node scripts/launch.mjs --open`.
По адресу http://localhost:4173 в верхней панели будет кнопка «Обновить SAIedu».

Кнопка скачивает изменения отслеживаемой ветки из `origin` и собирает их
отдельно. После успешного запуска новой сборки локальная ветка обновляется
в режиме fast-forward, а страница автоматически перезагружается.
При ошибке сборки текущая версия продолжает работать. При локальных правках
или расходящихся ветках причина отображается в интерфейсе.

Курсы, ответы и прогресс сохраняются в общей папке `data/`. Перед обновлением
приложение сохраняет резервную копию библиотеки в `data/backups/`, если файл
библиотеки уже существует. Git игнорирует эту папку и служебные сборки в
`.saiedu/`. Для восстановления из копии останови приложение и скопируй
нужный файл из `data/backups/` в `data/library.json`.
